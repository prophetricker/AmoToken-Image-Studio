# Nova Image Studio v0.8 候选能力灰度审计

日期：2026-07-07

## 结论

v0.8 将“我的素材”从候选能力中移出，作为提示词广场和生图任务复用闭环的一部分默认开放。普通用户默认可见的主功能为：生图工作台、Agent、反推提示词、我的素材，以及通过访问控制开放的提示词广场。

GIF、无限画布仍由构建时灰度开关控制。设置 `NEXT_PUBLIC_NOVA_CANDIDATE_MODES=1` 重新构建前端后，标签栏会额外显示 `动图生成` 和 `无限画布`。当前生产灰测不设置该变量，因此这两个入口不向普通用户默认开放。

## 我的素材

现状：
- 入口文件：`frontend/src/components/assets/AssetsWorkspace.tsx`
- 存储：浏览器本地 IndexedDB/localStorage，不依赖服务端账号体系。
- 默认可见：是，作为 v0.8 主链路的一部分。
- 支持图片素材：从生成结果、本地上传、随机图片、提示词广场图片等入口导入。
- 支持文字素材：从成功任务提示词、反推提示词、提示词广场、Agent 输入、手动新建等入口导入。

v0.8 增强：
- 文字素材具备名称、标签、备注、正文。
- 素材库卡片能显示文字素材的标题、标签、备注摘要和提示词片段。
- 文字素材可编辑名称、标签、备注和提示词内容。
- 素材库搜索覆盖文字素材的名称、标签、备注、来源和正文。
- 批量导出会包含文字素材文件，并在 README 中记录名称、来源、标签和备注。

灰度结论：
- 可进入 5-10 人小范围灰测。
- 需要向测试成员说明：素材保存在当前浏览器，本阶段不保证跨设备同步。
- 暂不做云端素材同步，避免引入账号体系、服务端存储成本和隐私边界变化。

## 提示词广场

现状：
- 入口文件：`frontend/src/components/PromptGallery.tsx`
- 卡片组件：`frontend/src/components/prompt-gallery/PromptGallerySubcomponents.tsx`
- 访问控制仍沿用现有提示词广场配置。

v0.8 增强：
- 提示词卡片可直接“用于生图”，导入主生图输入框。
- 详情弹窗仍支持保存为提示词素材。
- 带图片的提示词可继续浏览示例图、预览图片并添加图片到素材库。

灰度结论：
- 可继续随 v0.8 扩测。
- 后续可优化来源丰富度、分类筛选和缩略图质量，但不在本轮扩大为公开广场。

## GIF

现状：
- 入口文件：`frontend/src/components/GifGenerationWorkspace.tsx`
- 工作流：`frontend/src/hooks/useGifWorkflow.ts`
- 生成方式：先生成 3264x2448 的 4x3 网格图，再本地切帧编码 GIF。

兼容性判断：
- 当前筛选条件要求 image 系列模型同时支持自定义尺寸且 `maxOutputSize === '4K'`。
- AmoToken 公开主模型目前在前端注册为 `maxOutputSize: '2K'`，所以 GIF 工作区即使打开，也会显示没有可用 GIF 模型。

灰度结论：
- 不默认开放。
- 可在管理员环境验证“入口可见但无可用模型”的提示状态。
- 真正灰度前需要明确 4K 成本、稳定性和生成失败后的费用归因。

## 无限画布

现状：
- 入口文件：`frontend/src/components/canvas/CanvasWorkspace.tsx`
- 生成服务：`frontend/src/components/canvas/canvas-generation-service.ts`
- 能力：节点式画布、连线引用、局部生成、提示词广场导入、保存到素材库。

兼容性判断：
- 生成任务已走 Nova 任务队列，能够复用 AmoToken token-only 的主链路。
- 画布适合宽屏和复杂工作流，不适合直接作为新用户首屏能力。
- 参数组合复杂，用户容易选择过多节点或参考图，导致失败率和成本感知变差。

灰度结论：
- 不默认开放。
- 只建议管理员或核心测试成员灰度。
- 后续需要把画布节点生成的费用、耗时、失败原因接入与生图任务卡片一致的解释体系。

## 4K

现状：
- v0.8 默认不开放 4K。
- 4K 仍只作为 GIF 和高分辨率输出的能力前置条件评估。

灰度结论：
- 先不对普通用户承诺 4K。
- 需要继续记录 4K 单次成本、失败率、平均耗时和超时比例。
- 若后续开放，应采用单独模型/尺寸价格提示，不和 1K/2K 混成固定价格。

## 验收关注点

1. 主生图工作台不新增大块场景模板入口。
2. 成功任务、反推提示词、提示词广场都能沉淀到素材库。
3. 我的素材默认可见，且文字素材可识别、可搜索、可分类、可编辑。
4. GIF、无限画布只在 `NEXT_PUBLIC_NOVA_CANDIDATE_MODES=1` 构建时出现。
5. 面向普通用户的失败提示使用“爱词元”或“生图服务”视角，不暴露内部路由和服务术语。
6. 生产灰测继续保留 Basic Auth，Nova 容器仍只绑定 `127.0.0.1:3001`。
